Politique de Confidentialité

Dernière mise à jour : 22 Décembre 2025

Bienvenue sur ChouQuiz ! Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos données personnelles lorsque vous utilisez notre application mobile.

1. Données Collectées

ChouQuiz collecte les informations suivantes pour assurer le bon fonctionnement de l'application :

  • Compte utilisateur : Pseudo, avatar choisi, identifiant unique Firebase
  • Données de jeu : Scores, réponses aux quiz, historique de parties, classements, séries de victoires
  • Données sociales : Liste d'amis, demandes d'amitié, interactions sociales
  • Données techniques : Identifiant d'appareil, token de notification push, système d'exploitation
  • Données d'abonnement : Statut Premium, historique d'achats (via RevenueCat)

2. Services Tiers Utilisés

Nous utilisons les services suivants pour faire fonctionner l'application :

  • Firebase (Google) : Authentification anonyme, base de données Firestore, stockage des données utilisateur
  • RevenueCat : Gestion des abonnements Premium et achats in-app (iOS et Android)
  • Expo : Notifications push pour les rappels de quiz et les résultats
  • Apple App Store / Google Play Store : Distribution de l'application et gestion des paiements

Note importante : Nous ne vendons jamais vos données personnelles à des tiers. Vos données sont uniquement utilisées pour le fonctionnement de l'application.

3. Utilisation des Données

Vos données sont utilisées exclusivement pour :

  • Permettre le fonctionnement du jeu et des classements (quotidien, hebdomadaire, mensuel)
  • Gérer votre abonnement Premium et vos achats in-app
  • Envoyer des notifications push (rappels de quiz quotidien à 21h28, résultats, classements)
  • Améliorer l'expérience utilisateur et développer de nouvelles fonctionnalités
  • Gérer le système d'amis et les interactions sociales
  • Attribuer des badges et récompenses selon vos performances

4. Suppression des Données

Vous pouvez supprimer votre compte et toutes vos données à tout moment depuis l'application :

Paramètres → Zone de Danger → Supprimer mon compte

Cette action est irréversible et supprime définitivement :

  • Votre profil et toutes vos informations personnelles
  • Tout votre historique de quiz et scores
  • Vos relations d'amitié et demandes d'amis
  • Vos badges et récompenses
  • Vos entrées dans les classements
  • Vos tokens de notification push
  • Votre compte Firebase Authentication

Note : Si vous avez un abonnement Premium actif, vous devez d'abord l'annuler dans les paramètres de votre App Store ou Google Play Store avant de supprimer votre compte.

5. Vos Droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous avez les droits suivants :

  • Droit d'accès : Vous pouvez demander une copie de toutes les données que nous détenons sur vous
  • Droit de rectification : Vous pouvez modifier vos informations (pseudo, avatar) directement dans l'application
  • Droit à l'effacement : Vous pouvez supprimer votre compte et toutes vos données à tout moment
  • Droit à la limitation du traitement : Vous pouvez désactiver les notifications dans les paramètres
  • Droit à la portabilité : Vous pouvez demander l'export de vos données
  • Droit d'opposition : Vous pouvez refuser certaines utilisations de vos données

Pour exercer ces droits, contactez-nous à support@chouquiz.com

6. Sécurité des Données

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données :

  • Authentification sécurisée via Firebase Authentication
  • Chiffrement des données en transit (HTTPS)
  • Règles de sécurité Firestore pour limiter l'accès aux données
  • Stockage sécurisé des tokens et informations sensibles

7. Conservation des Données

Vos données sont conservées tant que votre compte est actif. Lorsque vous supprimez votre compte, toutes vos données sont supprimées définitivement dans un délai de 30 jours maximum.

8. Cookies et Technologies Similaires

ChouQuiz n'utilise pas de cookies sur le web. L'application mobile utilise uniquement des identifiants locaux pour le fonctionnement de l'application.

9. Modifications de cette Politique

Nous nous réservons le droit de modifier cette politique de confidentialité. En cas de modification importante, nous vous en informerons via l'application ou par email. La date de dernière mise à jour est indiquée en haut de cette page.

10. Contact

Pour toute question concernant cette politique de confidentialité ou vos données personnelles :

Email : support@chouquiz.com

Nous répondons à toutes les demandes dans un délai de 30 jours maximum.
